This is the personal portfolio website I created to showcase my hobby of Warhammer 40k. The site is hosted on GitHub pages, and the source code is available on my GitHub profile.

The site includes a front page with a photo of my Warhammer 40k army at the time, and a brief introduction to the in-universe lore surrounding my choice of faction.

The about page features two-sentance descriptors for each character and infantry unit in my army as well as links to an individual character page for each one.

The character pages each feature an image of the model I built, as well as a work of art showcasing what the character is meant to look like. It also contains a link to the respective character's wiki page and a short excerpt detailing their background and role.
