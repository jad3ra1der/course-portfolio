This is my senior capstone project for my Bachelors in Computing Applications at Texas Tech University. The project is a browser game inspired by classic JRPGs such as Final Fantasy and Dragon Quest. It was developed from scratch in using HTML, CSS, and JavaScript in RPGMaker MV. The game is hosted on GitHub pages, and the source code is available on my GitHub profile.

The original vision of the game was mostly preserved though the development process. Traverse through a linear sequence of areas, gaining upgrades along the way, and defeat a powerful enemy at the end. I also maintained my original plan of having some secrets dotted around the map for players to find on repeat playthroughs, a hint being given to their existence at the end of the game.

I arranged all of the game's music myself in FL Studio 20, using a SEGA Genesis sound chip plugin to emulate a classic RPG feel though the music.

The game was designed from scratch in RPGMaker MV, and it was my first time using that software. Through the course of development, I became much more familiar with the engine and it's inner workings and felt I gained quite a lot from the experience.
